# Hilltop Market Demo Site

A photo-heavy, SpaceX-inspired demo website for Hilltop Market & Exxon Mobil.

## 🚀 Live Site
**Target URL:** https://devinlegend.github.io/demosite1/

⚠️ **Action Required:** GitHub Pages must be enabled first (see setup instructions below)

## ✅ What's Complete
- ✅ 5 static HTML pages (Home, Meat, Produce, Groceries, Visit)
- ✅ Floating transparent header that becomes opaque on scroll
- ✅ Full-bleed hero images with SpaceX-inspired layout
- ✅ Sticky tap-to-call button (619-426-2200)
- ✅ Responsive design for all devices
- ✅ Real JPG images (40-48KB each, no placeholders)
- ✅ External CSS and JavaScript files
- ✅ GitHub Actions workflow configured
- ✅ All code committed and pushed to main branch

## ⚙️ Enable GitHub Pages (One-Time Setup)

1. Visit: https://github.com/DevinLegend/demosite1/settings/pages
2. Under "Build and deployment" → **Source**: Select "**GitHub Actions**"
3. Click **Save**
4. Wait 1-2 minutes for deployment
5. Site will be live at: https://devinlegend.github.io/demosite1/

- **SpaceX-inspired layout:** Photo-first, minimal copy
- **Floating header:** Transparent initially, solid white after scrolling
- **Full-bleed images:** 100vh hero sections

- **Warm palette:** Market-appropriate colors
- **No placeholders:** All JPG images included
